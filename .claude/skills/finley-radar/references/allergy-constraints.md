# Allergy & Dietary Constraints — Finley

## Tree-Nut Allergy — ABSOLUTE

**Never suggest, include, or reference any of the following:**

| Tree Nut | Also found in |
|----------|--------------|
| Almonds | Almond flour, marzipan, amaretto, almond milk, almond butter |
| Cashews | Cashew butter, many Indian/Thai dishes, vegan "cheese" |
| Pistachios | Baklava, some ice creams, certain Middle Eastern desserts |
| Walnuts | Brownies, banana bread, pesto (sometimes), some salads |
| Pecans | Pecan pie, pralines, some Southern desserts |
| Hazelnuts | Nutella, Ferrero Rocher, gianduja chocolate |
| Macadamia nuts | Hawaiian cookies, some chocolates |
| Brazil nuts | Mixed nuts, some trail mixes |
| Pine nuts | Pesto, some Mediterranean dishes |
| Chestnuts | Marron glacé, some stuffings |

**Restaurant vetting:** Always note "check menu for tree-nut-free options" when recommending a specific restaurant. Cuisines with high tree-nut risk: Thai, Indian, Middle Eastern, some Italian (pesto), pastry shops.

**Gifts with food:** No chocolate boxes, gift baskets, or baked goods unless the brand is explicitly nut-free/dedicated facility. Always flag this.

## No Alcohol

**Grayson and Finley do not drink alcohol. Never suggest:**
- Wine bars, wineries, vineyard tours
- Brewery or distillery tours
- Cocktail-making classes
- Bars as a venue (even if they serve food)
- "Romantic wine" anything
- Champagne toasts

**Substitutes for "celebratory drinks" framing:** sparkling water, mocktail bars, specialty coffee, boba tea, fresh juice bars.

## Safe Cuisine Categories (generally)
- Mexican (watch for mole — some contain nuts; ask)
- Japanese / sushi (generally nut-free)
- Mediterranean (pesto and some dishes — ask about pine nuts)
- American comfort food (check desserts)
- Pizza / Italian (check pesto)
- Korean BBQ
- Vietnamese (generally nut-free)
